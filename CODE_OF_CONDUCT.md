# Code of conduct

We are committed to a respectful, inclusive, and harassment-free community.

Contributors should be constructive, assume good intent, welcome questions, respect
privacy, and critique ideas rather than people. Harassment, discriminatory language,
threats, deliberate intimidation, and publication of another person's private
information are not acceptable.

Project maintainers may edit or remove contributions that violate these expectations
and may temporarily or permanently restrict participation. Conduct concerns should be
reported privately through the repository owner's GitHub profile. Do not put sensitive
details in a public issue.
